# 功能说明

cEmoji 的核心流程很简单：导入表情，点击复制，在其他软件里粘贴。

## 导入

- 支持 PNG、JPG、JPEG、GIF 图片。
- 支持导入 ZIP 表情包，ZIP 内可以包含子目录。
- 支持从剪贴板读取图片，适合配合 Snipaste、Win+Shift+S 等截图工具使用。
- 导入完成后会显示成功、重复跳过和失败数量。
- 已有相同内容的图片会自动跳过，避免重复表情。

## 使用

- 左键点击表情：复制到剪贴板。
- 在聊天、文档或其他软件中按 Ctrl+V 粘贴。
- 主界面顶部使用紧凑两行布局，可切换合集、搜索、筛选静态表情或 GIF，并执行上传、管理和更多操作。
- 可通过“表情包 / GIF”标签切换静态表情和 GIF 表情。
- GIF 表情会保留动图复制能力。
- 鼠标悬停在 GIF 上 1 秒会播放预览。
- 复制后可在聊天、文档或其他软件中按 Ctrl+V 粘贴。

## 本地合集

- 默认提供“本地”合集，顶部显示“本地”和当前/最近使用的另一个合集，其余合集可从“更多”中切换。
- 在合集“更多”菜单中可新建合集。
- 合集名字太长时会默认省略，鼠标悬停在合集标签上会滚动显示完整名称。
- 右键合集可重命名或删除；删除合集时，共享表情只移除合集关系，独占表情才删除本地文件。
- 图片、ZIP 和剪贴板导入会加入当前合集。
- 同一个表情文件可以加入多个合集，但本地只保存一份原图和缩略图。

## 云端表情包库

- 可在“更多”菜单中打开云端表情包库。
- 支持搜索云端图片文件名，并按“全部 / 表情包 / 动态表情包”筛选。
- 云端合集名字太长时，左侧合集列表和右侧当前合集标题都支持悬停滚动显示。
- 支持单张、多选或按合集下载到本地表情库。
- 下载云端单张或多选表情时可选择已有合集或新建合集；按云端合集导入时默认新建同名本地合集。
- 已下载的云端表情会显示标记，重命名后仍可识别。
- 云端预览会使用本地缓存，减少重复下载。

## 管理

- 搜索框可以按文件名快速筛选表情。
- 搜索只作用于当前标签，搜索框会显示当前分类的表情数量。
- 排序按钮可按时间或名称排列表情，并支持升序/降序切换。
- 右键表情可置顶、取消置顶、从当前合集移除或删除本地文件。
- 右键表情可重命名或打开文件所在位置。
- 置顶表情会排在前面，并持久保存。
- “管理”模式可快速从当前合集移除表情。
- “导出当前合集 / 导出所有表情包”可将对应范围的本地原图表情打包为 ZIP。
- “清空当前合集”会移除当前合集内容，共享表情只移除关系；“清空所有表情包”会删除全部本地表情和缩略图。

## 窗口和快捷键

- “始终置顶”可让窗口保持在其他窗口上方。
- Windows 上会尽量启用现代系统窗口效果，包括标题栏配色、圆角和可用时的 Mica 背景；不支持时会自动降级。
- 支持配置全局快捷键，用于呼出或隐藏主界面。
- 关闭或最小化会隐藏到系统托盘，退出入口位于托盘菜单。
- 程序只允许单实例运行，重复启动会唤起已经运行的窗口。
