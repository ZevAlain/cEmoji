# 使用教程

## 导入

点击“上传”后选择导入方式：

- 上传图片：选择 PNG、JPG、JPEG、GIF 文件。
- 上传 ZIP：批量导入压缩包内的表情。
- 读取剪切板内容：导入当前剪贴板中的图片。

cEmoji 会自动跳过重复图片，并在导入结束后显示统计。

导入的表情会加入当前选中的本地合集。同一个表情文件可以存在于多个合集，但本地只保存一份。

## 本地合集

- 顶部默认显示“本地”和当前/最近使用的另一个合集，点击可切换当前表情列表。
- 其他合集可从合集“更多”中选择；选中后会显示在“本地”后面。
- 在合集“更多”菜单中可新建合集。
- 合集名称太长时会默认省略，鼠标悬停在合集标签上会滚动显示完整名称。
- 右键合集可重命名或删除。
- 删除合集时，属于其他合集的表情只会移除合集关系；只属于这个合集的表情会删除本地文件。

## 复制

在主窗口左键点击表情即可复制。复制后切到目标软件，按 Ctrl+V 粘贴。

GIF 表情会保留动图；如果只是想预览，在 GIF 上停留 1 秒即可播放缩略图。

主窗口上方有“表情包 / GIF”标签。“表情包”显示静态图片，“GIF”只显示动态图片。

## 云端表情包库

在“更多”菜单中打开“云端表情包库”。

- 左侧可以搜索云端图片文件名并选择合集。
- 右侧可以在“全部 / 表情包 / 动态表情包”之间切换。
- 云端合集名太长时，左侧合集列表和右侧当前合集标题都可以悬停滚动查看完整名称。
- 点击图片可选中，多选后点击“下载选中”批量导入。
- 右键单张图片可直接下载到本地表情库。
- 点击“导入当前合集”可下载当前合集。

下载云端单张或多选表情时可选择目标本地合集；导入云端整合集时默认创建同名本地合集，同名则合并。

## 查找和置顶

- 在搜索框输入关键词，可以按文件名筛选。
- 搜索只会筛选当前标签中的表情。
- 点击排序按钮可以选择按时间或名称排序，并切换升序/降序。
- 右键表情选择“置顶”，常用表情会排在前面。
- 右键置顶表情可以取消置顶。
- 右键表情也可以重命名或打开文件所在位置。

## 导出

在“更多”菜单里可以选择“导出当前合集”或“导出所有表情包”。选择保存位置后会生成一个 ZIP 文件，里面包含对应范围的原图文件。

## 删除

- 右键表情选择“从当前合集移除”只会移除合集关系，不删除本地文件。
- 右键表情选择“删除本地文件”会从所有合集移除并删除本地文件。
- 点击“管理”进入快速移除模式，从当前合集移除表情。
- “清空当前合集”会清空当前合集；共享表情只移除合集关系，独占表情会删除本地文件。
- “清空所有表情包”会删除全部本地表情文件。

删除会移除本地文件，重要表情请先备份。

## 快捷呼出

可以设置一个全局快捷键，用于呼出或隐藏主界面。快捷键注册失败时，通常是被其他软件占用，换一个组合键即可。

如果开启“复制后隐藏”，点击表情复制后主窗口会自动隐藏到系统托盘。

点击窗口关闭按钮也会隐藏到系统托盘。如需退出 cEmoji，请在托盘菜单中选择“退出”。

Windows 上会尽量使用现代系统窗口效果，包括标题栏配色、圆角和可用时的 Mica 背景；系统不支持时会自动保持原生窗口样式。
